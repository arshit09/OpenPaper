Ask AI to design… Opus 5.5 · high

Built in. Just type.

Open a file and type into Ask AI to design… at the bottom of the canvas. Claude works with the same 37 tools an external agent gets, and you can stop it at any moment.

  • Your Anthropic keyPaste it once, set ANTHROPIC_API_KEY, or sign in with ant auth login.
  • Model and effortOpus 5.5 by default, or Sonnet 5.5 and Haiku 5.5. Effort from low to max.
  • Knows what you're looking atEvery message includes your file, page and selection.

Connect in one line.

Click Connect agent in the editor, or use the CLI. Then restart your agent so it picks up the server.

Terminal
# one client, several, or --all
$ openpaper install claude-code
$ claude mcp add openpaper --scope user -- \
    node /path/to/openpaper/packages/server/dist/cli.js mcp
{
  "mcpServers": {
    "openpaper": {
      "command": "node",
      "args": ["/path/to/openpaper/packages/server/dist/cli.js", "mcp"]
    }
  }
}
# any HTTP-capable client, while OpenPaper is running
http://127.0.0.1:29880/mcp

Agents see the canvas.

get_screenshot renders through headless Chrome or Edge, pixel-identical to the editor. Agents check their own work and fix what looks wrong.

  • Built-in guidesget_guide teaches agents to design in small steps, review their work and use tokens.
  • Image generationpaper-gen:// images with your own OpenAI or Gemini key.
