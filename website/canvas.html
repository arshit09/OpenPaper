Layout like CSS, because it is.

Every control maps to a CSS property. When a control isn't enough, edit the CSS directly.

  • Fixed, hug or fillSizing that behaves like the browser.
  • Free or flexAbsolute children, or column, row and wrap with gap, padding and alignment.
  • Fills, borders, radius, shadowsPlus every Google Font and your local fonts.

Tokens, used live.

Design tokens are CSS variables shared across the file. Change one and every layer that uses it updates. Agents can create a token set and restyle a design with it.
