Quick start

Up and running in minutes.

On Windows, download the app. On macOS and Linux, run three commands with Node.js 20.19+ and any Chromium browser.

Download for Windows Install guide Get started Connect an agent
Terminal
$ git clone https://github.com/arshit09/OpenPaper.git
$ cd OpenPaper && npm install && npm run build
$ npm start
# opens http://127.0.0.1:29880
